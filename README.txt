MAILPILOT — PACKAGE COMPLET DU SITE
================================

Ce package contient tout le site MailPilot prêt à être mis en ligne.

----------------------------------------
CONTENU DU PACKAGE
----------------------------------------

FICHIERS À UPLOADER SUR GITHUB (essentiels pour le site) :
  - index.html          → la page d'accueil avec logo + bouton démo
  - demo.html           → la démo interactive du système (20 secondes)
  - mentions-legales.html → page mentions légales obligatoire RGPD

FICHIERS BONUS (à utiliser ailleurs, PAS sur GitHub) :
  - logo-mark.svg       → logo MailPilot vectoriel haute qualité
  - mailpilot-demo.gif  → version animée pour signature email / réseaux
  - mailpilot-demo.mp4  → version vidéo HD pour LinkedIn / Twitter

----------------------------------------
COMMENT METTRE LE SITE EN LIGNE
----------------------------------------

ÉTAPE 1 — Aller sur GitHub
  - Connecte-toi sur github.com
  - Ouvre ton repo "mailpilote"

ÉTAPE 2 — Uploader les 3 fichiers HTML
  - Clique sur "Add file" → "Upload files"
  - Glisse-dépose les 3 fichiers : index.html, demo.html, mentions-legales.html
  - Confirme le remplacement si demandé
  - En bas, clique sur le bouton vert "Commit changes"

ÉTAPE 3 — Attendre 30 secondes
  - Vercel détecte le changement et redéploie automatiquement
  - Va sur ton URL (mailpilote.vercel.app) pour voir le résultat
